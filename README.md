# 每日看盤系統

依《看盤學習》12 張教學圖的 K 線規則，自動找出**買點 / 賣點**，
再用**前一晚台指期夜盤 ＋ 各國指數**評估台股當日或隔日漲跌，產出一頁 HTML 報告。

## 怎麼用
- **雙擊 `啟動看盤.bat`** → 自動抓資料、產生報告、打開瀏覽器。
- 或在終端機執行：
  ```
  python 看盤.py                # 加權指數 + 自選股.txt
  python 看盤.py 2330 3008 6488 # 臨時看別檔
  ```
- 自選股：編輯 `自選股.txt`，一行一檔，`#` 後面寫中文名。
- 報告存在 `報告/`，`報告/最新報告.html` 永遠是最新一份。

## 盤中即時監看（monitor.py）
https://bette0708-cyber.github.io/kanpan-daily/monitor.html
- 盤中（08:30～13:35）每 5 秒更新證交所即時報價；非交易時間每分鐘更新一次。
- 盯住用前一天收盤算好的關鍵價位：待確認的買點有沒有「站上訊號收盤＋量跟上」（確認中）、有沒有跌破停損。
- 提醒區列出跌破停損／開始確認的股票（手機支援時會震動）。大盤即時漲跌會對照早上的評估。
- 盤中K線還沒收完，只是參考；訊號照教學要等收盤才算數。
- 報價經由 Cloudflare Worker 轉接（`cloudflare/worker.js`，網址設定在 `監看設定.json`）：
  只轉接證交所報價、只回應自己的網頁、同一查詢 4 秒內共用快取。
  修改後重新部署：在 `cloudflare/` 資料夾執行 `npx wrangler@3.114.0 deploy`。

## 每週回測（回測.py）
看哪一種方法預測最準：https://claude.ai/artifact/2JNSDyrvqLUhGka7XbYFd8
- 每週六約 09:00 自動執行（Claude 桌面版排程「每週看盤回測」），也可以手動：`python 回測.py`
- 個股方法排行：12 種方法＋綜合分數，近 3 個月／1 年／5 年，預測隔日／5 日／20 日漲跌的「平衡命中率」
  （(看多時真的漲 + 看空時真的跌) ÷ 2，50% = 擲銅板）
- 大盤預測方式排行：夜盤、美股加權、費半、台積電ADR…，預測台股當天開盤／收盤方向
- 實際紀錄：`紀錄/個股預測.csv`、`紀錄/大盤預測.csv` 是每次執行看盤.py 自動存下的預測，週報會跟事後真實漲跌比對
- 每週排名存在 `紀錄/每週回測排行.csv`，週報上的 ▲▼ 是跟上週比的名次變化

## 自動排程
已在 Windows「工作排程器」建立 **每日看盤報告**：週一～週五 07:45 自動執行並打開報告。
- 電腦當時沒開機 → 開機後會自動補跑一次。
- 執行紀錄／錯誤：`報告/排程紀錄.txt`
- 改時間或停用：開始 → 搜尋「工作排程器」→ 工作排程器程式庫 → 每日看盤報告。

## 什麼時候跑最準
| 時間 | 評估什麼 |
|---|---|
| **早上 05:00 ～ 09:00（建議 07:30～08:30）** | 用剛結束的完整夜盤＋美股收盤 → **評估今天** |
| 盤中 09:00 ～ 13:30 | 同上（今天的K線還沒收完，型態會變動） |
| 收盤後 ～ 隔天 05:00 | 夜盤還沒結束 → 只用美股期貨即時＋歐股**暫估明天**；K線型態以今天收盤為準 |

## 判斷邏輯
**買賣點（patterns.py）**
1. 每根K線歸類成 16 種型態（大陽線、錘子紅K、倒錘、十字星…）。
2. 比對 2 根（吞沒、穿刺線、烏雲蓋頂、錘子底/鎚子頂）、3 根（晨星、黃昏星、三白兵、三烏鴉）、
   持續形態（上升/下降三法、看漲/看跌旗形）。
3. 「上漲後 / 下跌後」= 前 5 根漲跌超過 1 倍平均波動（ATR）。
4. 同方向分數加總 ≥ 2 → 標成買點/賣點。
5. **避坑：單一K線不算數** → 之後 1～2 天收盤延續方向且量能足夠，才算「已確認」。
6. **風控第一** → 停損 = 買點那根K線的最低點（賣點則是最高點）。

**大師方法綜合評估（masters.py、chips.py）**

除了你的教學，再加上 10 種國際公認、出書可查的方法和台股籌碼，每種給 −2～+2 分，加權後換算成 0～100 分：

| 類型 | 方法（出處） | 權重 |
|---|---|---|
| 教學 | K線型態（看盤學習 12 張圖） | 1.5 |
| 趨勢（中長線） | 葛蘭碧八大法則（Granville）、階段分析（Weinstein）、趨勢模板（Minervini）、道氏理論（Dow）、CAN SLIM 量價突破（O'Neil） | 各 1.0 |
| 動能（短線） | MACD（Appel）、KD（Lane）、RSI（Wilder）、布林通道（Bollinger）、OBV（Granville） | 各 0.75 |
| 籌碼 | 三大法人：外資＋投信近 5 日買賣超（證交所／櫃買中心） | 1.5 |

- 報告會分開顯示「短線分」和「中長線分」：短線高、中長線低 = 跌深反彈但趨勢還沒翻多。
- 報告最後有綜合分數的 5 年回測（分數區間 vs 之後 5／20 日報酬）。
- 法人資料存在 `快取/法人/`，抓過的日期不會重抓。

**大盤評估（outlook.py）**
- 分數 = 夜盤漲跌% × 60% ＋ 美股加權漲跌% × 40%
  （美股：台積電ADR 25%、費半 25%、那斯達克 20%、標普 20%、道瓊 10%）
- ≥ +1 強勢偏多｜+0.3～1 偏多｜±0.3 持平｜−0.3～−1 偏空｜≤ −1 強勢偏空
- 報告裡附「過去準不準」：拿同樣方法回測近幾個月，看方向命中率。
- 日經、韓股、恆生、上證、德股、英股、匯率列出來參考，不進分數。
